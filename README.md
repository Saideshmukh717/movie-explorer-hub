To run this project locally

first you need to have prerequisites

node.js
git
vscode (optional) 

first 
clone this repository 

then
cd movie-explorer-hub
change directory to cloned repository 
then
npm install
once installation completes
change edit the .env file 
to use your own omdb api key
then
npm run dev.

then open up a browser and enter local host or
the copy paste the local host link given in the terminal after run.

if you want to close the server 
go back to the terminal and press ctrl + c
